# 🚀 Yashdeep | Full Stack Web Developer Portfolio

A sleek, highly responsive, and modern personal portfolio website designed to showcase my full-stack development projects, technical skills, and professional profile. Built with a focus on UI/UX, mobile-first design, and seamless micro-animations.

**[🔴 View Live Portfolio Here] (https://my-portfolio-pi-nine-31.vercel.app)

## ✨ Features

* **Modern Aesthetic:** A striking dark theme utilizing soft glassmorphism, dynamic glowing gradients, and deep slate/emerald accents.
* **Responsive Architecture:** Fully mobile-first design ensuring perfect layouts across mobile devices, tablets, and wide-screen desktop monitors.
* **Interactive UI/UX:** Features smooth scroll navigation, interactive project presentation cards, and sophisticated hover micro-animations that elevate the user experience.
* **Dedicated Sections:** Cleanly separated sections for Home (Hero), About Me, Technical Skills, Featured Work, and Contact links.
* **Live Project Integration:** Direct external routing to live deployed applications hosted on Render and Vercel.

## 🛠️ Technologies Used

* **Frontend Framework:** React.js (via Vite)
* **Styling:** Tailwind CSS v4
* **Icons:** Lucide React & React-Icons (FontAwesome)
* **Deployment:** Vercel
